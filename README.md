# CLA signatures

Who has signed Kalamio's [Contributor License Agreement](https://github.com/kalamiohq/kalamio/blob/main/CLA.md).

`signatures/version1/cla.json` is written by the CLA workflow (`.github/workflows/cla.yml` on `main`) when a contributor comments `I have read the CLA Document and I hereby sign the CLA` on their pull request. Each entry records the GitHub login, the account id (what the check matches on, so renamed accounts still count), the signing comment and the pull request.

Entries with `"signed_via": "cla-assistant.io"` were signed through the hosted CLA Assistant before this workflow replaced it.

Don't edit this branch by hand, and don't delete it: the CLA check reads it on every pull request.
